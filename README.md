# Signatures courriel — Richmont Immobilier

Images des signatures courriel de l'équipe Richmont, servies par jsDelivr :

    https://cdn.jsdelivr.net/gh/teteapapineau/signatures-richmont@main/assets/<fichier>

- `richmont_logo_carre.png` : logo blanc sur carré marine, 400 px, affiché à 104 px

Ne pas renommer ni déplacer ce fichier : les signatures déjà installées
pointent sur cette adresse.

Les pages de signatures (HTML à copier dans Outlook ou Gmail) et le script qui
génère cette image restent chez Tête à Papineau : ils contiennent les
coordonnées de l'équipe.
